## 产品语义与剩余限制

- 休眠零 token = 安全语音路径不调用大模型/agent。检测声纹和唤醒仍需本地收音与计算。
- 唤醒采用两步：本人唤醒 → 确认 → 指令。优先安全，牺牲“一句话唤醒并执行”的便利。
- 安全模式半双工，推理与播放时不接收新命令。全双工、自然打断、流式字幕仍待完善。
- 声纹不是活体认证，无法声称能阻止本人录音、电视重放或克隆声音。
- 真人 FAR/FRR、噪声中的唤醒成功率未测。短唤醒片段和 1 秒窗口可能提高误拒绝。
- Windows 本地启动器使用 SAPI；旧 Edge 配置会联网。CLI/插件/MCP、主动屏幕功能有独立边界。
- 手动取消不能保证撤销已经产生的外部 agent 副作用；高风险工具仍需自身审批。
- 未进行 8 小时压力运行、设备拔插和系统睡眠恢复测试，不承诺常驻生产稳定性。

## 用户实机验收步骤

1. `start-local.ps1 -Mode enroll -User you`，本人录制三段；不要用生成音频代替本人。
2. `start-local.ps1 -Mode listen`，先自然说话但不说唤醒词：应保持待机，不出现指令派发。
3. 本人说“你好 D-VOICE”，等“我在，请说。”，再问“用一句话介绍你自己”。
4. 另一人说唤醒词或接话：应拒绝。重复至少 20 轮并记录误拒绝/误接收，勿直接降低阈值。
5. 本人说“休眠”，再说无唤醒词的指令：不得执行；重新唤醒应恢复。
6. 活跃状态静置 30 秒后讲话：应要求重新唤醒。
7. 关闭麦克风后，任何语音均不能唤醒；在 HUD 重新开启后恢复本地检测。
8. 最后再做噪声/距离和长期测试；在完成前保持候选版状态。
